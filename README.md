# IsThatAnAchievement

Client-only Fabric mod for Minecraft 26.2 that adds custom multi-tier Hypixel SkyBlock achievements, shown in an in-game achievements screen, as toasts and as chat lines. It uses no Hypixel API key.

## Install

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.19.5 or newer and Fabric API for Minecraft 26.2.
2. Download the latest jar from [Releases](../../releases/latest) and put it in your `mods` folder.
3. In game, press `K` or run `/ach` to open the achievements screen.

The mod checks this repository for new releases once per game session and offers a clickable update in chat. Nothing is downloaded until you click it.

This repository only hosts release builds.
